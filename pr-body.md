## For humans
Each agent now lives in its own folder in the config folder: its settings file, its instructions and character as plain Markdown, its notes and its skills. You can edit it by hand or keep it in git.
The first start of this build converts your old personas, profiles, notes, skills and routines once. It keeps the old files as dated backups and deletes nothing. `cooee config migrate --dry-run` shows the plan first.
A broken agent file hides only that agent. The log names the file and line, never what is in it.
