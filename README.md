# cooee

cooee is a phone and Mac app for your own personal agents. Each agent is a persona with a role, memory and skills;
it runs routines on a schedule or on events, reaches your accounts through connectors, and asks before anything it
should not do alone, so you approve from your phone. Coding agents are the first use, not the only one: agents
(Claude Code, Codex, Gemini, Pi, any ACP agent) run on one machine you own (Mac or Linux) as ACP sessions on
[shed](https://github.com/jirathip-dev/shed), keep working while you are away, and cooee pings your phone when they
need you. Self-hosted, reached over Tailscale. A cooee is the bush call you use to reach someone far off.

## Scope

cooee is the user-facing bots and chat: chat, personas, threads and the sign-in screens, and it draws other tools'
screens (drover's included) from their screens JSON. It calls shed for accounts, usage and runs, and keeps only the
policy and the UI over them. cooee sends every notification: drover emits events and cooee pushes them.

## Non-goals

- [shed](https://github.com/jirathip-dev/shed)'s jobs: accounts, credentials and secrets, the token proxy, usage,
  provider facts, the shed protocol (cooee uses shed-client), machines, VMs, installs and updates, process limits.
- [drover](https://github.com/jirathip-dev/drover)'s jobs: the workflow: issues, queues, lanes, reviews, merges. A new
  chat or thread feature for drover is built in cooee; drover adds only its backend (API, screens JSON), and its own
  phone page and terminal stay as they are.

## Setup

On a Mac with [shed](https://github.com/jirathip-dev/shed) and [Tailscale](https://tailscale.com/download) (signed in):

```sh
curl -fsSL https://raw.githubusercontent.com/jirathip-dev/cooee/main/scripts/install.sh | sh
```

It downloads main's latest release ([docs/releases.md](docs/releases.md)), then `cooee setup` checks shed's protocol
(cooee never installs or updates shed), writes the config, adds the agents, starts the service, runs
`tailscale serve`, checks it all with `cooee doctor` and prints a pairing code. Open that code on your phone. Run it
again any time; `--dry-run` writes nothing.

The Mac app ([`apple/README.md`](apple/README.md)) is a client only, like the phone: it lists a cooee running on the
same Mac first, as This Mac.
