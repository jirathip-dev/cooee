# 2026-11-21, #735: line cap raised to 39,000

**Old cap:** `line_cap` 37,800. **New cap:** `line_cap` 39,000. `apple_cap` stays at 26,000.

**Measured:** 37,195 non-test lines and 23,252 apple lines on staging at 42208cd (`scripts/line-cap.sh`, 2026-11-21).

**Reason:** #729's ADR (option D) splits `crates/cooee-server/src/hub.rs`. `scripts/line-cap.sh` counts a Rust file
only up to its first `#[cfg(test)]` (line 56 in `hub.rs`), so today 52 of its 741 non-blank lines count; the split
makes the rest count. The 13 slices add ~1,050 non-test lines (hub ~800, the other Rust slices ~250) against 605
headroom: 37,195 + 3 (open PRs) + ~1,050 ≈ 38,250, plus margin gives 39,000. The ~200 Swift lines fit the 2,748
apple headroom. `connectors.rs` has the same gap but is not split here, so it is not counted.

**Owner's pick:** owner, 2026-11-21, in #729's architecture review: approved option D with the cap raise sized for
all 13 slices, merged before the hub slice.
