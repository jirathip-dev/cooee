# Roadmap, in build order

cooee is a personal agent app: personas with skills, routines, connectors and their own browser, approved from your
phone. Coding agents are the first use. Steps and the issues in each are listed in the order they are built.

1. **Unblock:** a warm, pinned Apple CI [#486](https://github.com/jirathip-dev/cooee/issues/486), apple-check timed and its slow checks nightly [#487](https://github.com/jirathip-dev/cooee/issues/487), GitHub event routines [#261](https://github.com/jirathip-dev/cooee/issues/261).
2. **Learning loop:** Save as skill and Make this a routine [#495](https://github.com/jirathip-dev/cooee/issues/495), a background card expires as Deny [#505](https://github.com/jirathip-dev/cooee/issues/505), a consolidation routine [#219](https://github.com/jirathip-dev/cooee/issues/219), a starter skill library [#496](https://github.com/jirathip-dev/cooee/issues/496).
3. **Connectors:** the design [#497](https://github.com/jirathip-dev/cooee/issues/497), then the catalogue [#520](https://github.com/jirathip-dev/cooee/issues/520); hot files [#529](https://github.com/jirathip-dev/cooee/issues/529) and [#530](https://github.com/jirathip-dev/cooee/issues/530) before the calls [#521](https://github.com/jirathip-dev/cooee/issues/521); read and write tools [#522](https://github.com/jirathip-dev/cooee/issues/522), sign-in [#523](https://github.com/jirathip-dev/cooee/issues/523), the phone screens [#524](https://github.com/jirathip-dev/cooee/issues/524), mail and calendar [#525](https://github.com/jirathip-dev/cooee/issues/525).
4. **Approvals:** #505's background expiry first, then the provider contract [#503](https://github.com/jirathip-dev/cooee/issues/503) and its slices [#531](https://github.com/jirathip-dev/cooee/issues/531), [#532](https://github.com/jirathip-dev/cooee/issues/532), [#533](https://github.com/jirathip-dev/cooee/issues/533), [#534](https://github.com/jirathip-dev/cooee/issues/534), [#535](https://github.com/jirathip-dev/cooee/issues/535), [#536](https://github.com/jirathip-dev/cooee/issues/536), [#537](https://github.com/jirathip-dev/cooee/issues/537), [#538](https://github.com/jirathip-dev/cooee/issues/538); they supersede [#72](https://github.com/jirathip-dev/cooee/issues/72).
5. **Proactivity:** a heartbeat per persona [#498](https://github.com/jirathip-dev/cooee/issues/498), a signed webhook trigger [#499](https://github.com/jirathip-dev/cooee/issues/499), an inbox per persona [#220](https://github.com/jirathip-dev/cooee/issues/220).
6. **Browser:** a browser per persona [#160](https://github.com/jirathip-dev/cooee/issues/160), handoff asks [#164](https://github.com/jirathip-dev/cooee/issues/164), secret drop [#163](https://github.com/jirathip-dev/cooee/issues/163), replay frames [#161](https://github.com/jirathip-dev/cooee/issues/161), live view and take control [#162](https://github.com/jirathip-dev/cooee/issues/162), the Screen sheet [#166](https://github.com/jirathip-dev/cooee/issues/166), a take-control session saved as a skill [#500](https://github.com/jirathip-dev/cooee/issues/500).
7. **Any time:** what a test is for [#501](https://github.com/jirathip-dev/cooee/issues/501), this roadmap [#502](https://github.com/jirathip-dev/cooee/issues/502), session timings [shed#148](https://github.com/jirathip-dev/shed/issues/148) then warm sessions [shed#147](https://github.com/jirathip-dev/shed/issues/147).
8. **Later:** the Mac app through TestFlight [#485](https://github.com/jirathip-dev/cooee/issues/485), styles as packs [#488](https://github.com/jirathip-dev/cooee/issues/488).
9. **Desks (parked):** sandboxed machines, [#168](https://github.com/jirathip-dev/cooee/issues/168) to [#173](https://github.com/jirathip-dev/cooee/issues/173).
